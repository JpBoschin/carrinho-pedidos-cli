# 🛒 CLI de Validação de Pedidos e Carrinho (Python)

Projeto prático em Python desenvolvido para simular a validação de regras de negócio de um carrinho de compras, calculando descontos dinâmicos, validação de cupons e aplicação de taxa de entrega/frete grátis.

## 📌 Funcionalidades
- **Entrada Interativa**: Coleta de dados do cliente e valores dos produtos via terminal.
- **Validação de Cupons**: Aplicação de regra condicional para cupons promocionais (ex: `IFOOD10`).
- **Lógica de Frete Grátis**: Verificação automática de elegibilidade para frete grátis com base no valor total do pedido.
- **Relatório de Checkout**: Exibição detalhada e formatada do resumo financeiro do pedido.

## 🛠️ Conceitos de Python Utilizados
- Variáveis e conversão de tipos (`float`, `str`).
- Operadores matemáticos e de comparação.
- Estruturas de decisão (`if`, `elif`, `else`).
- Formatação de strings (`f-strings` e precisão decimal `:.2f`).

## 🚀 Como Executar
```bash
python carrinho_cli.py
